EMIANO（エミアノ）ブランドのWordPressプラグインに関する共通の問い合わせ窓口です。

## ドキュメント

各プラグインの使い方や、有料版（PRO）の情報は、
[ドキュメント一覧](docs/README.md)をご覧ください。

## お問い合わせ方法

上部の問い合わせメニュー、または[お問い合わせテンプレート一覧](https://github.com/litty-co-jp/emiano-support/issues/new/choose)から、内容に合ったテンプレートを選んで投稿してください。

投稿前に、同じ内容のIssueがないか確認してください。投稿には以下の情報を記載してください。

- 製品名
- 製品のバージョン
- お問い合わせ内容
- 不具合の場合は、利用環境と再現手順

## 投稿前の注意事項

- **このリポジトリとIssuesの内容は、インターネット上に公開されます。**
- APIキー、パスワード、アクセストークンなどの認証情報を投稿しないでください。
- 氏名、メールアドレス、住所などの個人情報を投稿しないでください。
- 購入・決済情報、非公開の文書、顧客情報などの機密情報を投稿しないでください。
- スクリーンショットやログを添付する場合は、機密情報が含まれていないか確認し、必要な箇所を伏せてください。
- セキュリティ上の脆弱性については、悪用につながる詳細を公開Issueに投稿しないでください。
